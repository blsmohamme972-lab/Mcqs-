# Slide mnemonics: سلايد = جلسة = صورة واحدة

## طريقة الاستخدام

1. افتح جلسة Claude Code على هذا المستودع (هذه هي **الجلسة الرئيسية**).
2. ارفع ملف الـ PowerPoint، واكتب: `/slide-mnemonics`
3. الجلسة الرئيسية:
   - تستخرج كل السلايدات وتعرض لك قائمتها؛
   - تسألك أي السلايدات تريد (وتقترح تخطي سلايد العنوان والشكر)؛
   - تفتح **جلسة منفصلة لكل سلايد** باسم `Slide 01 · <عنوان السلايد>`.
4. افتح جلسة أي سلايد في تطبيق Claude. ستجد فيها:
   - خطة الصورة: ماذا يعلّم كل جزء؛
   - عدد من البرومبتات (Part 1/3، Part 2/3، ...) حسب كثافة السلايد.
5. ولّد الصور في ChatGPT، وأرسلها **لنفس جلسة السلايد** بالترتيب (Part 1 أولًا).
6. جلسة السلايد:
   - تراجع كل صورة (النصوص والمعلومات)؛
   - تدمجها في **صورة واحدة متصلة بحجم سلايد (16:9، 3840×2160)**؛
   - تكتب تحتها **شرح الأستاذ** + أسئلة اختبر نفسك.
